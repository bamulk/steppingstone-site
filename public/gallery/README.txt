Drop gallery photos in this folder (JPG, PNG or WebP).

- They appear on the Gallery page in filename order, so name them 01-..., 02-... to set the order.
- The filename becomes the caption: "02-rio-linda-pool.jpg" shows as "Rio linda pool".
  Camera names like IMG_1234.jpg, and any name with a long number or id in it, get no caption.
- iPhone HEIC files won't display in browsers; convert them to JPG first.
- The Gallery link appears in the menu once there is at least one photo here.
